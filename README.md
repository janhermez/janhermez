## Featured project

### [OpenScience AI Agent](https://github.com/janhermez/openscience-ai-agent)

A **local-first Python AI agent** for exploring scholarly publications and checking metadata completeness.

- **Python + FastAPI:** REST endpoints for publication search, metadata checks, and agent interaction.
- **OpenAlex:** optional integration with a public scholarly metadata API; synthetic records for offline demos.
- **Ollama + Qwen3:** local LLM with function/tool calling.
- **Testing and tooling:** pytest, Docker, and GitHub Actions.

**Status:** experimental MVP. Agent-output evaluation and more advanced metadata checks are planned, not yet implemented.
